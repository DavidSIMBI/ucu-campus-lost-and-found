# UCU Campus Lost and Found System

A web-based Lost and Found Management System for Uganda Christian University (UCU).

The application will allow students to report lost or found items, search listings, and submit private ownership claims. An administrator will review claims and confirm when an item has been returned.

## Technologies
- Frontend: React
- Backend: Node.js and Express
- Database: MySQL

## Main folders
- `frontend/` — the website students and administrators will use.
- `backend/` — the server and application logic.
- `database/` — database planning and MySQL files.
- `documentation/` — project requirements, design notes, testing and report.

## Current stage
This repository contains the initial project foundation only. No application features or database scripts have been implemented yet.
